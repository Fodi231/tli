# Запустить готовую Web-версию

Папка `web_release/` содержит готовую сборку TechLife 0.11.1 с фотографическими внутренностями, новыми инструментами, осмотром ОС и складными моделями. Иконка ТехМаркета, обои и уведомления из 0.8 сохранены. Графический движок включён в сборку, без обязательной загрузки CanvasKit с внешнего CDN.

Из папки проекта запусти локальный HTTP-сервер, например при установленном Python:

```bash
python -m http.server 8080 --directory web_release --bind 127.0.0.1
```

Открой http://127.0.0.1:8080 в современном браузере. Двойной щелчок по `index.html` не заменяет HTTP-сервер. Для остановки — Ctrl+C.

Для публикации можно разместить содержимое `web_release/` на обычном статическом HTTPS-хостинге. Сама игра автоматически не опубликована. AI-сервер уже опубликован и подключён: игрокам не нужны ключ, аккаунт Google или настройка модели. Для карты и ИИ нужен интернет. Лимиты сервиса и информация для владельца — в AUTOMATIC_AI_RU.md. Сохранение остаётся в браузере, отдельно для каждого адреса и браузерного профиля.

Android, Windows и iOS собираются из Flutter-исходников по README. Устанавливаемых APK/EXE/IPA в архиве нет.
