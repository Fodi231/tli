# TechLife 0.4.0 — ремонт за столом

Відкрий **Ремонт → Навчальний стіл**, щоб одразу спробувати заміну дисплея. Навчання безкоштовне: гроші, запчастини й репутація не змінюються. Для замовлення клієнта: **Робота → Прийняти → Почати ремонт**.

## Що додано

- Майстерня у стилі наданого зображення, з окремими інтерактивними деталями смартфона.
- Ремонти дисплея, батареї, камери та роз’єму, а також діагностика. Різні послідовності для різних деталей.
- Сім інструментів: рука, викрутка, прогрів, присоска, лопатка, пінцет і тестер.
- Гвинти з трьома обертами, утримання для прогріву й перевірок, перетягування деталей, від’єднання та приєднання шлейфів.
- Зворотне складання, повернення гвинтів і три фінальні тести.
- Збереження замовлень та кожної виконаної дії, включно з частково відкрученим гвинтом. Можна вийти в магазин і продовжити.
- Списання однієї запчастини під час встановлення. Виплата один раз після фінального тестування.
- Українська, російська та англійська. Миша й сенсорний екран, портретна й альбомна орієнтації, масштабування.

## Керування

| Дія | Керування |
| --- | --- |
| Обрати інструмент | Кнопка внизу; на ПК — клавіші 1–7 |
| Відкрутити / закрутити гвинт | Три натискання на його головку |
| Від’єднати / приєднати конектор | Лопатка, натискання на виділений конектор |
| Зняти / встановити деталь | Затиснути й перетягнути в зазначену зону |
| Прогріти, вимкнути, перевірити | Потрібний інструмент, утримання 1,2 с |
| Наблизити | Кнопки +/− або щипок двома пальцями |
| Перемістити наближену сцену | Потягнути вільне місце килимка |
| Скинути масштаб | Кнопка між + і − |
| Підказки | Лампочка або H |
| Вийти зі столу | Стрілка вгорі або Esc |

Панель інструментів на вузькому екрані прокручується горизонтально й автоматично підводить потрібний інструмент у видиму частину на новому етапі. Інструмент усе одно обирає гравець. Блакитний контур показує джерело дії, зелений — місце, куди перенести деталь. Магазин доступний із верхньої панелі. Якщо запчастина закінчилась, купи її й повернись у Ремонт.

Неправильний інструмент або дія не за порядком збільшують лічильник помилок. Збережено формулу початкової гри: −12% від базової винагороди за помилку (зі страхуванням удвічі менше), мінімум 40%; сертифікати додають свій бонус. Коротке утримання чи відпускання деталі поза лотком дозволяє повторити рух без штрафу.

## Межі цієї версії

Детальний 2D-режим працює для смартфонів iPhone, Galaxy та Pixel із каталогу. Їхні внутрішні компоненти — стилізована спільна ігрова схема, а не точні копії реальних моделей. Планшет і консоль зберегли класичний ремонт. Пересування персонажа, пайку, розширення сервісу й нові системи бізнесу це оновлення не додає.

Запчастини обліковуються **за категорією**, як у вихідній грі; сумісність за конкретною моделлю не змінювалась. Інструменти доступні одразу. Навчальний стіл не видає кар’єрних сертифікатів. Старі збереження з балансом, складом і курсами завантажуються; замовлення, які стара версія не зберігала, відновити неможливо.

## Запуск і перевірка

Перевірена конфігурація: Flutter 3.47.7 / Dart 3.13.5. Мінімум проєкту: Flutter 3.29 / Dart 3.7. Після розпакування:

```bash
flutter create --project-name techlife --org com.techlife --platforms=android,ios,windows,linux,macos,web .
flutter pub get
flutter test
flutter run
```

Команда `flutter create` генерує стандартні платформні оболонки; вихідний архів їх теж не містив. Готовий процес GitHub Actions має окремі збірки Android, Windows, Web та непідписаної iOS-версії; перевірки виконуються перед збірками. iOS потребує підпису для встановлення, desktop-збірки — відповідної ОС та її інструментів. Для Linux/macOS використовується той самий Dart-код і стандартна платформна оболонка.

Архів містить вихідний код, а не встановлювані APK/EXE/IPA. Результати локальної перевірки наведено в `VALIDATION.md`.
