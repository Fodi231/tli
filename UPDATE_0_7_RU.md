# TechLife 0.7.0 — новый ТехМаркет

Интерфейс собран из работающих Flutter-виджетов по пяти присланным макетам. Новая иконка с устройствами используется в исходниках и готовой Web-версии.

## Обновление с 0.6.0

Распакуй `techlife_0_7_update.zip` и скопируй содержимое вложенной папки `techlife` в корень своего Flutter-проекта с заменой совпадающих файлов. Архив содержит только новые и изменённые файлы относительно последней 0.6.0 с предыдущей иконкой. Точный перечень находится в `CHANGED_FILES.txt`.

Для более ранней версии используй полный `techlife.zip`. Пользовательское игровое сохранение не входит в архив и не сбрасывается. Новые поля мигрируют из старого сохранения автоматически.

Основные изменения: `lib/ui/market/`, `lib/core/game_state.dart`, `lib/core/models.dart`, `lib/core/market/market_models.dart`, `lib/core/i18n.dart`, `lib/core/app_info.dart`, `lib/ui/phone_shell.dart`, `pubspec.yaml`, `assets/icon/`, четыре новых изображения в `assets/market/`, настройки иконок, `web/`, тесты и документация.

После копирования выполни `flutter pub get` и обычную сборку своей платформы. GitHub workflow уже генерирует иконки Android/iOS/Web и копирует Windows ICO. Для локальной замены иконок существующего native-проекта см. `ICON_UPDATE_RU.md`.

## Web

При обновлении опубликованной игры обнови `web_release/`, включая JavaScript. В патч входят только изменённые файлы этой папки. Для нового сайта используй целиком `web_release/` из полного архива. Сохранение привязано к браузеру и адресу; обновление по прежнему адресу его сохраняет. Графический движок включён в сборку без обязательной загрузки с внешнего CDN.

## Работающие возможности

- Каталог: категории, поиск, фильтры бренда/состояния/цены, сортировка, карточка устройства, избранное, переход к продавцу.
- Избранное: поиск, настоящие счётчики и настройка ценовых уведомлений. Цена сравнивается со снимком при добавлении. Уведомление появляется при реальном снижении цены игрового каталога после обновления; случайных демонстрационных скидок нет.
- Продажа: выбор своей техники, название/описание/цена, до 10 фото JPEG/PNG, удаление фото, фото модели по умолчанию, автосохранение черновика и возобновление из профиля. Фото хранятся локально; одно ограничено 1 МБ, общий объём также ограничен.
- Состояние соответствует инвентарю и ремонту. Во время активного ремонта продажа заблокирована. Публикация создаёт переписку покупателя; передача денег и устройства выполняется только кнопкой подтверждения.
- Сообщения: поиск, покупки/продажи, последние реплики, время, статусы и счётчик непрочитанного. Переписка адаптируется к короткому экрану и клавиатуре.
- Профиль: имя, репутация, фактические покупки/продажи, баланс, объявления, черновики, история, RU/EN/UK, помощь и настройки.
- Автоматический ИИ сохраняется; игрок не вводит ключ. Ручной API доступен только администратору. Пароль TLIF-FT не менялся.

## Решения по макетам

ТехМаркет светлый во всех игровых темах. Существующая экономика сохранена в игровых долларах; гривневые числа на демонстрационных картинках не подменяют баланс. Комиссия равна нулю, как в текущих правилах.

Каталог содержит прежние 14 объявлений и семь моделей смартфонов. Ноутбуки и консоли показывают пустое состояние категории. Новые устройства и их ремонт в этой версии не добавлены. Фото iPhone 13 не подписано как 13 Pro, Galaxy S23 — как Ultra.

Счётчики показывают прогресс игрока. Процент успешных сделок рассчитан по выигранным и закрытым переговорам; до первых завершённых переговоров показано «—». Фиктивные отзывы и просмотры не подставляются.
