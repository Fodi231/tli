## Исправление 0.5.1 (история; сейчас ручной режим только у администратора)

В настройке Gemini добавлен явный выбор **Gemini API · AI Studio** или **Vertex / Agent Platform Express**. Ключ больше не отправляется автоматически в другой Google API при ошибке. Ожидание ответа — 45 секунд; Gemini 3 использует `thinkingLevel: low`, без устаревшего параметра temperature. Версия 0.5.0 использовала 12 секунд.

Если ключ создан в AI Studio, выбери Gemini API. Для ключа Cloud Express выбери Vertex и включи `aiplatform.googleapis.com` в проекте этого ключа. Увеличение тайм-аута не исправляет HTTP 403 и не гарантирует доступность серверов Google.

## Что уже есть (MVP)

- Экран блокировки → главный экран с иконками, баланс и репутация, док, анимация открытия приложений

- **Обучение** — цепочка курсов с сертификатами (+5% к наградам за каждый)
- Статистика, достижения, уведомления, настройки (язык RU / EN / UK, проверка ИИ, сброс)

## 1. Установка

1. Установите Flutter: https://docs.flutter.dev/get-started/install
2. Проверьте: `flutter doctor`
3. Распакуйте проект и в его папке выполните (создаёт папки платформ `android/`, `ios/`, `windows/`, `web/`, ваш код не трогает):

```bash
flutter create --platforms=android,ios,windows,web .
flutter pub get
```

## 2. Автоматические ответы Gemini

Вход в аккаунт Google, API-ключ и выбор модели игроку не нужны. Игра обращается к настроенному серверу TechLife. Обычный профиль и настройки показывают только проверку связи.

Для разработчика: [AUTOMATIC_AI_RU.md](AUTOMATIC_AI_RU.md). Ключ хранится в секретах сервера Sites. Клиентские сборки не содержат общего ключа. При недоступности сети, сервера, Gemini или при достижении лимита используются помеченные игровые реплики.

Личный API доступен как дополнительный ручной режим после входа в админ-панель. Возврат к общему серверу — кнопкой «Автоматический ИИ» в профиле администратора.

## Админ-панель

Настройки → **Админ-панель** (красная иконка). Пароль по умолчанию: **TLIF-FT**; проверка использует солёный SHA-256 хеш. После 5 неверных попыток вход блокируется на 60 секунд.

Внутри: журнал ошибок (ИИ, игра, сеть, карта; кнопки «Копировать» и «Очистить»), деньги и репутация, создание заказов и сделок, телепорт по городам, проверка ИИ с текстом ошибки, смена модели, имитация «нет интернета», экспорт и импорт сохранения.

**Свой пароль:** посчитайте хеш `sha256("TechLife|admin|v1|" + пароль)`, например в терминале:

```bash
printf '%s' 'TechLife|admin|v1|ВАШ_ПАРОЛЬ' | sha256sum
```

Для другого пароля передайте результат (64 символа) локальной сборке: `--dart-define=ADMIN_HASH=<хеш>`. Workflow по умолчанию использует запрошенный пароль TLIF-FT.

## Ключи ИИ

Поддерживаются ключи Google с выбором API вручную: **Gemini API · AI Studio** или **Vertex / Agent Platform Express**. Выбирайте сервис, для которого создан ключ. Проверить связь и увидеть точный текст ошибки можно в Админ-панели → ИИ → «Проверить ИИ».

## 4. Сборка

### Android (APK)
Перед релизной сборкой добавьте разрешение интернета в `android/app/src/main/AndroidManifest.xml` (над `<application`):

```xml
<uses-permission android:name="android.permission.INTERNET"/>
```

Затем:

```bash
flutter build apk --release
# файл: build/app/outputs/flutter-apk/app-release.apk
```
Для Google Play: `flutter build appbundle --release` и подпись своим ключом (https://docs.flutter.dev/deployment/android).

### Windows (EXE)
Нужен Windows 10/11 и Visual Studio 2022 с компонентом «Desktop development with C++».

```bash
flutter build windows --release
# папка: build/windows/x64/runner/Release  (раздавайте всю папку, а не один .exe)
```

### iOS (IPA)
Только на Mac с Xcode и аккаунтом Apple Developer.

```bash
flutter build ipa --release
# файл: build/ios/ipa/*.ipa
```
Нет Mac? Используйте сборку в GitHub Actions (п. 5) — получите неподписанный IPA, подписать его можно позже.

### Web
```bash
flutter build web --release
# папка: build/web
```
Выложите содержимое `build/web` на любой статический хостинг: GitHub Pages, Netlify, Firebase Hosting, Cloudflare Pages. Если сайт лежит не в корне домена, добавьте `--base-href "/имя-папки/"`.

## 5. Сборка всех платформ в облаке (без Mac и Windows)

1. Создайте репозиторий на GitHub и загрузите проект (вместе с папкой `.github`)
2. Вкладка **Actions → Build all platforms → Run workflow**
3. Через несколько минут внизу страницы запуска скачайте артефакты: APK, Windows, Web, неподписанный IPA

## 6. Заметки

- Карта берёт плитки с `tile.openstreetmap.org` — для небольшого проекта это нормально, для большого трафика возьмите коммерческий провайдер (MapTiler, Stadia, Mapbox) и поменяйте `urlTemplate` в `lib/ui/apps/map_app.dart`.
- Названия городов и координаты: `lib/core/catalog.dart`. Новый город — одна строка в списке `cities`.
- Все тексты: `lib/core/i18n.dart` (ru / en / uk в одном месте).
- Баланс игры (цены, награды, налоги, шанс заказов): `lib/core/catalog.dart` и `lib/core/game_state.dart`.
