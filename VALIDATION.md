# Перевірка TechLife 0.5.0

Дата: 23 жовтня 2026. Linux, Flutter 3.47.7 stable, Dart 3.13.5.

| Перевірка | Результат |
| --- | --- |
| `flutter analyze --no-pub` | No issues found |
| `flutter test --no-pub --reporter expanded` | 36 тестів пройдено |
| `flutter build web --release --no-pub` | Успішна release-компіляція; результат у `web_release/` |
| Wasm dry run | Успішний; окрема Wasm-збірка не випускалась |
| Android APK / Windows EXE / iOS IPA | Локально не збирались і на пристроях не перевірялись; workflow збережено |
| Реальний Gemini API | Не викликався: ключ користувача не надано. Перевірено HTTP-запити та помилки з MockClient |

Перевірено повний цикл: купівля несправного апарата → підтвердження → ремонт із одноразовим списанням деталі → власне оголошення → торг → підтверджена перепродаж. Є перевірки недостатнього балансу, повторної купівлі одного лота, подвійного продажу, блокування продажу під час ремонту, відновлення листування й обраного зі збереження. Номери моделей та обсяг пам’яті у звичайному повідомленні не вважаються ціною.

HTTP-тести перевіряють URL моделі Gemini, заголовок `x-goog-api-key`, дані пристрою й історію розмови, відокремлення службових thinking-частин від відповіді, локальне рішення про ціну, резервну відповідь після HTTP 429 та скидання стану очікування. Витрати API та робота з конкретним обліковим записом Google не перевірялись.

Для кожної із семи моделей пройдено чотири сценарії заміни. Окремо перевірено, що центри всіх інтерактивних деталей і зон перенесення збігаються з геометрією рендера, у широкому й портретному режимах. Перевірено міграцію старих сесій ремонту. Координати компоновок і кількість клейових язичків різні; точність усіх механічних деталей не заявляється.

Реальні натискання у віджетах перевіряють пошук, обране, відкриття лота, перехід у розмову, узгодження ціни й покупку. Екран блокування, домашній екран, розгортання Dynamic Island та маркет перевірені на 320×568, 390×844, 844×390 і 1366×768 із текстом 140%. Ті самі розміри перевірено для майстерні. Знімки у `preview/` отримані з Flutter-віджетів, а не згенеровані за описом.

Web-версія скомпільована; окреме керування нею в браузері та перевірка продуктивності на фізичних мобільних пристроях не проводилися. Некритичне попередження компілятора про необов’язковий шрифт CupertinoIcons збережено від початкового проєкту. Новий інтерфейс використовує включені MaterialIcons та Roboto.
