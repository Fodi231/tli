# Перевірка TechLife 0.4.0

Дата: 23 жовтня 2026. Середовище: Linux, Flutter 3.47.7 stable, Dart 3.13.5.

| Перевірка | Результат |
| --- | --- |
| `flutter analyze --no-pub` | No issues found |
| `flutter test --no-pub --reporter expanded` | 21 тест пройдено |
| `flutter build web --release --no-pub` | Успішно: ✓ Built build/web (тимчасова копія з типовою Web-оболонкою) |
| Android APK / Windows EXE / iOS IPA | Локально не збирались і на пристроях не перевірялись |
| Linux / macOS native | Локально не збирались |

Автоматичні тести охоплюють усі п’ять сценаріїв ремонту смартфонів; порядок дій і вибір інструмента; утримання, перетягування та часткові оберти гвинтів; відновлення збереження; нестачу запчастин; одноразове списання і виплату; конкуренцію двох замовлень за одну запчастину; безкоштовне навчання; завантаження старого формату збереження; повноекранний вхід і вихід із майстерні.

Екран перевірено при розмірах 390×844, 844×390, 1366×768 і 320×568 з текстом, збільшеним до 140%. Знімки в `preview/` отримані з реального віджета Flutter; це не макети, згенеровані з опису.

Web-компіляція також проходить автоматичний Wasm dry run; це перевірка сумісності, а не випуск окремої Wasm-збірки. Нативні платформи використовують спільний код, але потребують своїх інструментів і окремої перевірки на пристроях. В архіві немає встановлюваних нативних пакетів.

Некритичне попередження Web-компілятора: SDK згадує необов’язковий шрифт CupertinoIcons, якого не було у вихідному проєкті. Інтерфейс майстерні використовує включені MaterialIcons та Roboto; попередження не зупиняє збірку.
