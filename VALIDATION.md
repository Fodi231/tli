# Перевірка TechLife 0.7.0

Дата: 23 жовтня 2026. Linux, Flutter 3.47.7 stable, Dart 3.13.5.

| Перевірка | Результат |
| --- | --- |
| `flutter analyze --no-pub` | No issues found |
| `flutter test --no-pub --reporter expanded` | 66 тестів пройдено; 1 окремий live-тест пропущено за замовчуванням |
| `flutter build web --release --no-pub --no-web-resources-cdn` | Успішна release-компіляція; результат у `web_release/` |
| Серверний AI-проксі | Перевірка 0.6.0: 10 тестів пройдено, production build успішний; у 0.7.0 сервер не змінювався |
| Реальний Gemini через сервер | Перевірено у 0.6.0 з порожнім ключем: ping, питання продавцю, ціна 190; у 0.7.0 live-виклик повторно не запускався |
| Захист ігрових грошей | У новому UI чернетка та публікація не змінюють баланс 1500; після підтвердження продажу за 410 баланс 1910 |
| CORS / health | Перевірка 0.6.0: OPTIONS 204, health 200; серверний протокол збережено |
| Android APK / Windows EXE / iOS IPA | Локально не збирались і на пристроях не перевірялись; workflow збережено |

Нові тести 0.7.0 перевіряють п’ять вкладок на RU/EN/UK та чотирьох розмірах із текстом 140%, відновлення чернетки, публікацію й підтверджену продаж через кнопки, фільтр цін, клавіатуру, фото та непрочитані повідомлення з однаковим часом. Збережені тести перевіряють автоматичний режим без ключа, відсутність особистих ключів у запиті до проксі, обробку ліміту, збереження вибраного режиму й ping. Серверні тести перевіряють валідацію, обмеження тіла запиту, CORS, квоти, безпечні повідомлення про помилки та передачу Google-ключа лише сервером.

Реальний інтеграційний тест викликається явно через `RUN_LIVE_AI=1 flutter test test/integration/managed_live_test.dart`. Він витрачає квоту сервісу; звичайний запуск тестів його пропускає. Реальна перевірка була виконана окремо й успішно завершена. Ключ не вбудований у клієнт, Web-збірку або тести.

Перевірено повний цикл: купівля → підтвердження → ремонт із одноразовим списанням деталі → власне оголошення → торг → підтверджена перепродаж. Є перевірки недостатнього балансу, повторної купівлі, подвійного продажу, блокування продажу під час ремонту, відновлення листування й обраного. Номери моделей та пам’ять не вважаються ціною.

Для кожної із семи моделей перевірено чотири сценарії заміни, геометрію інтерактивних зон та міграцію старих сесій. Компоновки різні; точність усіх механічних деталей не заявляється.

Flutter-віджетами перевірено пошук, обране, відкриття лота, розмову, торг і покупку. Екран блокування, домашній екран, Dynamic Island, маркет і майстерню перевірено на 320×568, 390×844, 844×390 і 1366×768 із текстом 140%. Знімки `preview/` отримані з віджетів.

Web-версія скомпільована; керування нею в браузері та продуктивність на фізичних мобільних пристроях окремо не перевірялись. Попередження про необов’язковий шрифт CupertinoIcons не заважає збірці; інтерфейс використовує MaterialIcons та Roboto.
