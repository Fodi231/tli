# Автоматический ИИ — TechLife 0.6

Игрок открывает переписку и получает ответы Gemini. Ключ, модель и API ему вводить не нужно.

## Как работает

Игровой клиент обращается к `https://techlife-ai-service.brainycloud19.chatgpt.site/api/chat`. Сервер составляет запрос для игрового продавца или покупателя и вызывает `gemini-3.5-flash-lite`. Ключ Google хранится как секрет серверной среды. Его нет в Flutter-исходниках, Web-сборке и параметрах GitHub-сборки.

Запрос содержит модель устройства, тип сделки, объявленную неисправность, язык, имя персонажа, результат локального торга и до восьми последних сообщений. Каждое сообщение ограничено 1000 символами. Личные API-ключи игрока серверу не передаются. Произвольные system prompts, внешние URL и выбор модели сервер не принимает. Сервер сам задаёт роль персонажа и характеристики семи поддерживаемых моделей.

Оплата и передача игрового устройства, как прежде, выполняются только после подтверждения игроком. ИИ пишет реплику, а правила цены остаются в игре.

## Ограничения

- Серверный предел по умолчанию: **1000 допустимых обращений в день** суммарно и **60 в час с одного IP**. Считаются попытки вызова, включая тест связи и ошибки Google.
- Общий дневной счётчик обновляется по дате Europe/Kyiv; часовой IP-счётчик — по часовым интервалам.
- Счётчики хранятся в D1 и сохраняются при перезапуске сервера. В таблице используется хеш с секретной солью, а не исходный IP. Старые записи очищаются после истечения срока.
- Это ограничения расхода общего ключа, а не авторизация игроков. У публичного сервиса нет защиты от всех видов злоупотребления; общий предел ограничивает число допустимых вызовов Google.
- Вызовы Gemini требуют интернета и доступности сервера. При ошибке, перегрузке или лимите игра использует помеченные игровые ответы; настройки от игрока не требуются.
- Текст переписки отправляется в серверный сервис и Google Gemini. Не отправляйте в игровые диалоги личные данные.

## Для владельца

Сервис размещён через Sites: https://techlife-ai-service.brainycloud19.chatgpt.site

Переменные среды сервиса: `GEMINI_API_KEY` (секрет), `RATE_LIMIT_SALT` (секрет), `AI_DAILY_LIMIT` (по умолчанию 1000). Изменение ключа делается на сервере и применяется публикацией версии. Ключи в код и клиентскую сборку не вставляйте. Серверные исходники сохранены в связанном с этим Site репозитории.

Проверка состояния без обращения к Google: `GET /api/health`. Проверка ответа Gemini: `POST /api/chat` с JSON `{"mode":"ping"}`; она расходует одно обращение.

В обычных настройках игры ключей больше нет. Вход администратора `TLIF-FT` открывает дополнительные настройки личного API и возврат к автоматическому режиму. Персональные ключи старых сохранений остаются в локальных данных для ручного режима; в автоматическом режиме используется сервер.

Адрес собственного совместимого сервера можно задать владельцем при сборке: `--dart-define=TECHLIFE_AI_URL=https://example.com/api/chat`. Это настройка сборки для владельца, а не шаг для игрока.
